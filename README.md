# Cultura Negra - Site Educativo

Site educativo sobre personalidades e elementos importantes da cultura negra brasileira e internacional.

## 📋 Sobre o Projeto

Este site foi desenvolvido como uma homenagem à Carolina Maria de Jesus e apresenta informações sobre:

- **Carolina Maria de Jesus** - Escritora brasileira, autora de "Quarto de Despejo"
- **Machado de Assis** - Maior escritor brasileiro do século XIX
- **Angela Davis** - Filósofa e ativista americana
- **Capoeira** - Arte marcial brasileira de origem africana

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Design Responsivo

## 📱 Funcionalidades

- Layout responsivo para dispositivos móveis
- Navegação intuitiva
- Conteúdo educativo e histórico
- Animações e interatividade

## 🎯 Objetivo

Promover o conhecimento sobre a cultura negra e suas contribuições para a sociedade brasileira e mundial.
